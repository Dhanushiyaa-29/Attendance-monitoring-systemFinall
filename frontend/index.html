Face Processing Pipeline

Three-stage AI pipeline for accurate, robust face recognition

01
🔍 SSD MobileNet V1 — Detection
Detects face locations in the input image. Returns bounding boxes with confidence scores. Only high-confidence detections proceed to the next stage.
02
📐 68-Point Landmarks — Alignment
Identifies key facial landmarks (jawline, eyes, nose, mouth) for geometric face alignment, ensuring consistent orientation before recognition.
03
🧠 Face Recognition Net — Embedding
Generates a 128-dimensional numerical face embedding. The system compares embeddings using Euclidean distance rather than raw pixel comparison.
